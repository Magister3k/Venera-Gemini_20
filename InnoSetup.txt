Я подготовил профессиональный скрипт для создания инсталляционного пакета (сценарий `installer.iss` для **Inno Setup** и скрипт автоматизации `.ps1`). 

### Что делают эти скрипты:
1. **`installer.iss` (Настройка сборки .exe)**:
   * Создает красивый и быстрый установщик с максимальным сжатием (LZMA2).
   * Автоматически помещает все зависимости, включая `config.toml`, собранный React-фронтенд (`react-ui/dst`), скрипты, манифесты и папки настроек (`settings`). Конфиги копируются только если они не существуют (`onlyifdoesntexist`), чтобы при обновлении поверх старой версии пользовательские настройки не были затёрты.
   * Во время установки автоматически вызывает внутреннюю команду `venera.exe --install_srv` (скрытно) для регистрации службы Windows в системе.
   * При деинсталляции автоматически вызывает `venera.exe --uninstall_srv`, чтобы чисто удалить службу без "хвостов" в реестре.
   * Создает ярлыки на рабочем столе и ярлык для запуска "Диагностики (GUI)".

2. **`scripts/create_installer.ps1` (Автоматизация)**:
   * Данный скрипт сначала запускает `build.ps1` (для пересборки `.exe` и `React` UI).
   * Затем он ищет на компьютере установленный `Inno Setup 6`. Если он есть, запускается сборка `.exe` пакета.
   * Если Inno Setup не установлен, скрипт автоматически откатывается на создание Portable-версии (`Venera_Portable.zip`), упаковывая всё необходимое в единый портативный архив.

Для создания инсталлятора вам достаточно установить бесплатный Inno Setup (https://jrsoftware.org/isdl.php) и просто выполнить:
```powershell
.\scripts\create_installer.ps1
```
Установщик появится в автоматически созданной папке `Output/`.
