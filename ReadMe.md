# Venera
Система сбора идентификаторов в потоке пакетных данных.

## Описание
Модульная программа под Windows x64 с распределенной структурой для сбора, фильтрации и сохранения данных в базу PostgreSQL с использованием промежуточного кэша в in-memory СУБД DragonflyDB. Программа поддерживает два режима работы: приложение в системном трее и служба Windows.

## Архитектура
Программа состоит из следующих основных компонентов:
1. **Процессы сбора (Tshark)**: Захват данных с сетевого интерфейса или из файлов, парсинг JSON.
2. **Кэширование (DragonflyDB)**: Буферизация сырых данных в структурах `List` для сглаживания пиковых нагрузок.
3. **Менеджер задач**: Отслеживает наполнение кэша и запускает рабочие процессы (`goroutines`).
4. **Рабочие процессы обработки**: Извлекают данные, фильтруют их (белый/черный списки) и помещают в структуры `Sorted Set` для подготовки к экспорту.
5. **Экспорт в БД (PostgreSQL)**: Пакетный перенос отфильтрованных и отсортированных данных в реляционную базу.
6. **Веб-интерфейс**: Управление процессами, просмотр статистики и логов, настройка системы (порт 8080 по умолчанию).

## Требования
- ОС: Windows x64
- СУБД PostgreSQL (создать базу `Venera` скриптом `sql/create_pg_db.sql`)
- СУБД DragonflyDB (можно запустить через Podman/Docker)
- Tshark (утилита из пакета Wireshark)

## Сборка
Выполните скрипт сборки в PowerShell:
```powershell
.\build.ps1
```
Или вручную:
```bash
go mod tidy
go build -o venera.exe
```

## Использование
```
venera.exe [опции]

Опции:
  -h, --help                 Показать это сообщение
  -v, --version              Показать версию программы
  -d, --diagnose             Запустить диагностику системы
```

### Запуск в качестве службы
Для установки в качестве службы Windows (требуются права Администратора):
```powershell
.\install_venera.ps1
```

Для удаления:
```powershell
.\uninstall_venera.ps1
```

## Конфигурация (`config.toml`)
При первом запуске будет создан файл `config.toml` с настройками по умолчанию:
- Пути к исполняемым файлам (Tshark, Podman).
- Пути к файлам фильтров (`settings/generic.flt`, `settings/generic.ctr`).
- Настройки подключения к DragonflyDB и PostgreSQL.
- Системные пороги для защиты от переполнения (RAM, Disk).

## Интерфейс
После запуска (если настроен режим `tray` или запущен веб-сервер), интерфейс доступен по адресу:
`http://localhost:8080` (порт можно изменить в `config.toml`).

## Логирование
Логи сохраняются в папку `Logs/`. Поддерживается автоматическая ротация и сжатие старых логов в форматы `.gz`.
